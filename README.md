# Dynamix Artwork Archive — implementation handoff

This folder currently contains a researched implementation plan, not a completed gallery. The intended product is an **original Dynamix-only** artwork archive matching the browsing, provenance, acquisition, and bilingual documentation features of [`../deemo`](../deemo), adapted to Dynamix sources. Dynamix Universe-only artwork is excluded, as confirmed by the user.

Start with **[docs/implementation/README.md](docs/implementation/README.md)**. It links the source research, architecture contracts, agent assignments, Git workflow, acceptance checks, and release hold.

The future implementation should finish on `main`, pass independent code review and validation, and be pushed to the intended public GitHub repository, `FridrichMethod/dynamix`, after checking the authenticated owner and any existing repository. GitHub Pages deployment, version tags, and GitHub Releases remain on hold until a later release instruction.

Planning date: **2026-10-10**. Reference snapshot: DEEMO commit `b14bf0d5f5a05e5382c319f3fd5019a4936820b8`. The research does not establish that every artwork or artist master is publicly available. Downloaded originals, previews, unavailable candidates, and coverage gaps must be reported separately.
